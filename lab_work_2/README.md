## О проекте

Репозиторий содержит решения четырёх задач по обработке и анализу данных на Python. Для каждой задачи подготовлен отдельный модуль `solution.py` и входной файл с данными. Запуск всех решений собран в Jupyter Notebook `example.ipynb`.

## Реализованные задания

| № | Модуль | Что делает |
|---|---|---|
| 1 | `task_1/solution.py` | Находит выбросы в данных о посещаемости с помощью межквартильного размаха (IQR) и выводит их количество. Проверяет допустимость входных значений. |
| 2 | `task_2/solution.py` | Подсчитывает расходы участников похода и формирует список денежных переводов для выравнивания итоговых затрат. |
| 3 | `task_3/solution.py` | Разбирает записи о заказах пиццы, в том числе записи с разными разделителями и форматами дат и цен. Выводит популярность пицц, выручку по дням, самый дорогой заказ и среднюю стоимость заказа. Некорректные строки пропускаются. |
| 4 | `task_4/solution.py` | Обрабатывает файл почтовых метаданных `mbox.txt`: подсчитывает количество писем от каждого отправителя, выводит адрес отправителя с наибольшим числом писем и список найденных адресов. |

## Установка

Перейдите в корневую папку проекта и создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте окружение.

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

Установите зависимости проекта:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Формат входных данных

- **Задача 1 — `task_1/data.txt`:** в первой строке указано количество наблюдений, далее — количество присутствовавших студентов для каждого занятия.
- **Задача 2 — `task_2/data.txt`:** первая строка содержит имена участников, вторая — количество покупок, последующие строки — имя плательщика и сумму покупки.
- **Задача 3 — `task_3/data.txt`:** каждая строка содержит дату, название пиццы и цену. Встречаются разные допустимые разделители, варианты записи даты и десятичной части цены; неподходящие строки игнорируются.
- **Задача 4 — `task_4/mbox.txt`:** текстовый файл с метаданными писем в формате MBOX; адрес отправителя извлекается из строк, начинающихся с `From `.
