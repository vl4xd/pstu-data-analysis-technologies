## Описание работы

В лабораторной работе проводится анализ данных о недвижимости.

В ходе работы выполняются:
- Первичный анализ данных, проверка типов, пропусков и дубликатов.
- Построение корреляционной матрицы и тепловой карты (heatmap).
- Выбор наиболее коррелирующих с целевым признаком MEDV факторов.
- Построение диаграмм рассеяния (pairplot).
- Снижение размерности признаков RM и LSTAT с помощью метода главных компонент (PCA).
- Построение и оценка модели линейной регрессии.
- Исследование влияния выбросов на качество прогнозирования.
- Построение Ridge-регрессии с L2-регуляризацией.
- Построение полиномиальной регрессии третьей степени с L2-регуляризацией.
- Сравнение моделей по метрикам R² и RMSE.

## Установка

Перейдите в корневую папку проекта и создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте окружение.

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

Установите зависимости проекта:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск

Убедитесь, что датасет `boston.csv` находится в директории `data/`.

Запустите Jupyter Notebook из корневой папки проекта:

```bash
jupyter notebook solution.ipynb
```

После открытия ноутбука выполните все ячейки последовательно.

## Результаты

В ходе лабораторной работы были построены и сравнены следующие регрессионные модели:

| Модель | R² (test) | RMSE (test) |
|---|---:|---:|
| Линейная регрессия | 0,6270 | 5,1106 |

Наилучший результат достигнут при использовании полиномиальной регрессии третьей степени с L2-регуляризацией.

Коэффициент детерминации на тестовой выборке составил 0,7947, а RMSE — 3,7920.
